# 发布范围与源码来源

仓库由原完整项目重新分类整理，原解压目录保留不变。

## 应用源码

- 保留 Flask 接口、配置、原始 AnalysisPipeline 模块和训练入口。
- 将前端迁移到 frontend/，已训练权重与初始权重分别迁移到 models/trained/、models/pretrained/。
- 将三张合成示例图迁移到 samples/，同步配置与样本生成脚本。
- 原始源码和权重在整理前核对原包清单的 SHA-256；目录配置按新位置修改。
- 提供新的安装、前台启动、数据导入和文件检查脚本。所有公开运行说明以当前 README 为准。

## 发布范围

| 资料 | 处理方式 |
| --- | --- |
| 应用代码、训练入口、配置、依赖 | 上传 |
| 前端所需静态资源 | 上传，保留第三方库文件 |
| 两份已训练权重、两份初始权重 | 上传 |
| 三张合成示例图 | 上传 |
| 论文源文件、Word 草稿、论文图表、历史基线 | 分类至 docs/papers/ |
| 答辩 PPT、讲稿、预览 | 分类至 docs/presentations/ |
| 原始交付说明、历史依赖版本 | 在 docs/reference/ 保留作历史参考 |
| 原始训练数据及老师提供的完整资料 | 保留在原解压目录；通过数据导入脚本接入本地 data/datasets/ |
| 申报书 | 含联系信息，保留于本地 docs/private/ |
| 原包清单、原运行验证报告 | 保留于本地 docs/private/，不作为本次运行验证证据 |
| 上传图、生成结果、运行日志、Python 缓存、tmp/、测试副本 | 不上传 |

原始数据存在多套重复副本，训练使用数据导入脚本统一目录；GitHub 仓库不重复存放这些副本。

## 验证记录

docs/checks/ 分别记录静态文件检查和应用运行检查。历史论文数值、接口 targets 字段以及合成演示图不构成当前模型性能证据。发布整理没有重新训练模型，没有验证 GPU 环境，也没有补造缺失的多缺陷权重。
